# 隐私与剪贴板行为

Catch 的内容存储在你选择的本地目录。应用没有内置内容上传、分析或账户服务。你选择的外部编辑器、接收拖拽的 App，或自行配置的云盘同步服务，遵循它们自己的数据行为。

## 文字采集

快捷键只在你主动触发时读取当前来源的选区，不因普通浏览或复制建立历史。读取不到可靠选区时可以使用兼容复制；你可以关闭它。

兼容复制等待按键释放，暂存原剪贴板可读内容，对绑定来源执行一次 Cmd+C，只接受本次新产生的普通文字。快照仅在内存，受可读性和大小限制；带受保护标记的内容不保存。若检测到较新复制，保留较新内容。

系统剪贴板没有通用的跨进程原子回滚或可靠写入者身份。因此还原是尽力行为，无法排除所有极小竞争或超时后晚到事件。无法完整备份时会取消并提示；也可手动复制后显式选择“收藏剪贴板文字”。

## 截图和文件

截图先进入持久临时列表，不自动到期。点击收藏后才创建长期 MD。收起卡片不删文件；明确删除与恢复按资料库/系统废纸篓规则执行。共享附件的引用不确定时保守保留。

每次主动收藏独立成文档。外部编辑优先于缓存，无法安全解析时保留原文件，不用旧缓存覆盖。

## 诊断

正常诊断避免输出选中文字、截图内容和敏感 URL。请使用无敏感的合成内容报告问题。源码可供你审阅这些行为；本说明不是对所有系统竞争或第三方 App 行为的绝对保证。
